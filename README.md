## 你的网络到台北到底多少毫秒

买前自己测一遍，比看任何测评都准：

1. 向客服要一个台北节点的测试 IP。
2. 用你平时那条宽带 ping 100 次，看平均延迟和丢包率，不要只看一次结果。
3. traceroute 看路由有没有绕到日本或美国再回台北，绕一次就多 100ms。
4. 晚上 20:00 到 23:00 再测一遍，白天的数据参考价值有限。

主要用户在台湾或亚太其他地区，这套流程可以省掉一半。主要用户在大陆并且对延迟敏感，先测再决定买不买。
